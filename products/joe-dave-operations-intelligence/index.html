Joe&dave Operations Intelligence · Independent product · Independent custom application · Cloudflare Workers + D1 · No standalone application architecture.
A · EVIDENCE, NOT GUESSWORK

Operations adviser.

Run a read-only, evidence-based review of live company records, surface exceptions and save lightweight offline notes. Findings use explicit rules and source records; this is not a generative AI chatbot.

Live findings

Awaiting review

Sign in, then run a review to analyse records available to your account.

Offline workspace notes

This device only

Notes are saved locally on this device and are not synced to the server. Do not put passwords, payroll details or confidential customer information here. Financial transactions are never queued for automatic replay.

Connectivity & safe sync

Checking

The app checks connectivity continuously. Offline notes stay on this device; live records and transactions require a server connection.

Never silently replay financial writes

Invoices, receipts, supplier bills and journals require a live response to avoid duplicate postings.

Read-only advice

The adviser does not post, approve, pay or alter records.

Human approval

Recommendations are prompts for review, not accounting, tax, HR or legal decisions.

Operating specification

A · Guardrails
Metrics

Receivables = invoice balances still unpaid. Payables = supplier bills still outstanding. Stock alerts use recorded reorder levels. Profitability uses posted revenue and recorded costs only. Missing data is shown as unavailable, never zero by assumption.

Permissions

The API is the authority for workspace access. The interface must not treat hidden buttons as security. Sensitive actions must be checked server-side; advice is read-only.

Alert rules

Prioritise overdue balances, low-stock exceptions, unreconciled bank lines and accounting-period risks. Each finding should point back to the source record and state the evidence used.

Auditability

Posted financial changes should retain actor, time, source record and status. Never fabricate audit entries or replace the accounting ledger with dashboard totals.
